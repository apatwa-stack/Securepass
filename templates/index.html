PBKDF2 Password Hashing

secrets + hashlib

Uses Python's secrets.token_bytes() to generate a cryptographically strong 32-byte salt, and hashlib.pbkdf2_hmac with HMAC-SHA256.

OWASP recommended minimum for PBKDF2-HMAC-SHA256 is 600,000 iterations.

REST API Documentation & Endpoints

RESTful JSON API

SecurePass provides a complete REST API over HTTP/JSON. Test the endpoints below using curl or any HTTP client.

POST /api/generate Generate password(s) with configurable parameters
Request Body (JSON)
{
  "length": 20,
  "include_uppercase": true,
  "include_lowercase": true,
  "include_digits": true,
  "include_symbols": true,
  "exclude_ambiguous": false,
  "count": 1
}
cURL Example
curl -X POST http://127.0.0.1:5000/api/generate \
  -H "Content-Type: application/json" \
  -d '{"length": 20}'
POST /api/hash Hash a password using PBKDF2-HMAC-SHA256
Request Body (JSON)
{
  "password": "MasterSecretPassword123!",
  "iterations": 600000,
  "algorithm": "sha256"
}
cURL Example
curl -X POST http://127.0.0.1:5000/api/hash \
  -H "Content-Type: application/json" \
  -d '{"password": "secret"}'
POST /api/verify Verify password against PBKDF2 hash (Constant-time)
Request Body (JSON)
{
  "password": "MasterSecretPassword123!",
  "encoded": "pbkdf2:sha256:600000$salt_hex$hash_hex"
}
Response (JSON)
{
  "valid": true,
  "message": "Password matches hash"
}
POST /api/analyze Calculate Shannon entropy & strength in C via ctypes
Request Body (JSON)
{
  "password": "k9#Vp!82Lq@mZ19"
}
Response (from C Engine)
{
  "engine": "Native C Library via ctypes",
  "shannon_entropy_bits": 58.61,
  "strength_score": 95,
  "strength_label": "Very Strong",
  "crack_time_human": "Centuries"
}
GET /api/vault Retrieve stored vault items from SQLite
Query Parameters
user_id: optional integer
cURL Example
curl http://127.0.0.1:5000/api/vault
